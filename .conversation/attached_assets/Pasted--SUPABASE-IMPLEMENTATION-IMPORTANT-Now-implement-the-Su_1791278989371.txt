# 2. CREATE DATABASE SCHEMA

Create a complete SQL setup file such as:

supabase/schema.sql

Create these tables:

## profiles

Columns:

id UUID PRIMARY KEY REFERENCES auth.users(id) ON DELETE CASCADE

full_name TEXT NOT NULL

email TEXT

phone TEXT

role TEXT NOT NULL DEFAULT 'citizen'

created_at TIMESTAMPTZ DEFAULT NOW()

Allowed roles:

admin
technician
citizen

---

## streetlights

id UUID PRIMARY KEY DEFAULT gen_random_uuid()

light_code TEXT UNIQUE NOT NULL

latitude DOUBLE PRECISION NOT NULL

longitude DOUBLE PRECISION NOT NULL

location TEXT NOT NULL

zone TEXT

status TEXT NOT NULL DEFAULT 'working'

created_at TIMESTAMPTZ DEFAULT NOW()

updated_at TIMESTAMPTZ DEFAULT NOW()

Allowed status:

working
failed
maintenance
inactive

---

## reports

id UUID PRIMARY KEY DEFAULT gen_random_uuid()

streetlight_id UUID REFERENCES streetlights(id) ON DELETE CASCADE

reported_by UUID REFERENCES profiles(id) ON DELETE CASCADE

issue_type TEXT NOT NULL

description TEXT

priority_score INTEGER DEFAULT 0

priority_level TEXT DEFAULT 'low'

status TEXT DEFAULT 'open'

created_at TIMESTAMPTZ DEFAULT NOW()

updated_at TIMESTAMPTZ DEFAULT NOW()

Allowed priority levels:

low
medium
high
critical

Allowed statuses:

open
assigned
in_progress
resolved
verified

---

## maintenance_tasks

id UUID PRIMARY KEY DEFAULT gen_random_uuid()

report_id UUID REFERENCES reports(id) ON DELETE CASCADE

technician_id UUID REFERENCES profiles(id) ON DELETE CASCADE

assigned_by UUID REFERENCES profiles(id) ON DELETE SET NULL

status TEXT DEFAULT 'assigned'

remarks TEXT

assigned_at TIMESTAMPTZ DEFAULT NOW()

started_at TIMESTAMPTZ

completed_at TIMESTAMPTZ

Allowed statuses:

assigned
in_progress
resolved
verified

---

## notifications

id UUID PRIMARY KEY DEFAULT gen_random_uuid()

user_id UUID REFERENCES profiles(id) ON DELETE CASCADE

message TEXT NOT NULL

is_read BOOLEAN DEFAULT FALSE

created_at TIMESTAMPTZ DEFAULT NOW()

# 6. ROLE-BASED SECURITY

Implement Supabase Row Level Security.

Do NOT simply hide UI buttons and consider that security.

The database itself must restrict access.

### Citizen

Citizen can:

READ streetlights

INSERT reports where:

reported_by = authenticated user

READ only their own reports

READ their own notifications

Cannot:

* Read other citizens' reports
* Assign technicians
* Modify maintenance tasks
* Change their role
* Access admin data

### Technician

Technician can:

READ relevant streetlights

READ reports associated with assigned maintenance tasks

READ their own maintenance tasks

UPDATE their own assigned maintenance tasks

READ their own notifications

Technician cannot:

* Assign tasks
* Change user roles
* Modify another technician's tasks
* Access admin-only data

### Admin

Admin can:

READ all profiles

READ all streetlights

READ all reports

READ all maintenance tasks

READ all notifications

INSERT/UPDATE required application records

Assign technicians

Verify completed tasks

Manage streetlight/report information where required

Do not make the entire database publicly readable.
